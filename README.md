# 🔏 极简文本加密助手 (SimpleTextEncryptor)

一款专为 Windows 打造的极简、轻量、秒开的文本文件加密与安全查看工具。

基于工业级 **AES-256-CBC** 加密标准，支持右键直接打开 `.wt` 加密文件、输入密码即刻调起记事本查看与编辑，并在记事本关闭后自动感知改动、重新加密回写并粉碎明文缓存。

---

## ✨ 核心特性

- ⚡ **无感秒开**：原生轻量化实现，冷启动耗时 `< 0.4s`，无后台运行时开销。
- 🛡️ **内存级安全**：临时明文仅在编辑时受控暴露，关闭记事本即刻覆盖擦除，防止磁盘数据恢复。
- 🔐 **工业级强加密**：
  - **密钥派生 (KDF)**：PBKDF2 + HMAC-SHA256（100,000 次迭代计算，32 字节 Key）
  - **对称加密**：AES-256（CBC 模式，PKCS7 填充）
  - **防彩虹表**：每个文件独立生成 16 字节高熵随机 Salt 与 16 字节随机 IV
- 🎨 **现代 Fluent 暗黑界面**：
  - 完美契合 Windows 11 深色模式与原生无锯齿圆角阴影。
  - 支持窗口随意拖拽、输入框呼吸焦点高亮、明暗密码切换（👁）。
  - **支持文件直接拖拽**：将文本或加密文件直接拖进窗口即可自动识别。
- 🔗 **一键无感关联**：
  - 点击“关联右键菜单”即可将 `.wt` 后缀与本工具绑定。
  - **100% 免管理员提权**（写入当前用户注册表），告别烦人的 UAC 弹窗提示。
- 🔄 **跨版本完全互通**：提供高性能 **C# 版**（推荐日常使用）与 **Python 版**（跨平台参考实现），二者加密格式完全兼容、无缝互解。

## 🛠️ 构建与编译

### 方法一：Windows 内置编译器一键构建（推荐，无需安装任何 SDK）
Windows 10 / 11 系统出厂均内置了 .NET Framework C# 编译器 (`csc.exe`)：
1. 进入 `CSharp` 目录。
2. 双击运行 **`build.bat`**。
3. 耗时约 1 秒，即可直接生成体积仅 `~150 KB` 的单文件绿色版 **`文本加密助手.exe`**。

### 方法二：使用现代 .NET SDK 编译
如果你已安装 .NET 8 或 .NET 9 SDK：
```powershell
cd CSharp
dotnet build -c Release
```

## 📖 使用说明

1. **直接加密文本**：
   - 将任意 `.txt` 文本拖入程序窗口，或点击“选择文件”，输入密码后点击“立即加密”。
   - 原始文件将自动转换为安全的 `.wt` 加密文件。
2. **安全解密与查看**：
   - 首次使用点击“🔗 关联 .wt 到系统右键”。
   - 以后直接双击任意 `.wt` 文件，输入密码即可在记事本中无缝阅读或编辑。
   - 编辑完成后直接保存并关闭记事本，程序会自动更新加密内容。
